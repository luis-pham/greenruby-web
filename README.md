# Green Ruby Cruises: Next.js frontend

Public website for greenrubycruises.com. Content comes from the Laravel CMS (`../cms-develop`) through its read-only Content API. Pages are prerendered on the server, so crawlers and AI bots get complete HTML. The migration plan is kept as internal notes, outside this repository.

## Run locally

1. Start Laravel from the `feature/content-api-v1` branch:
   ```
   cd ../cms-develop && MAIL_MAILER=log php artisan serve --host=127.0.0.1 --port=8000
   ```
   `MAIL_MAILER=log` makes test contact-form emails go to `storage/logs` instead of being sent.
2. Copy `.env.example` to `.env.local` and fill it in. `CONTENT_API_KEY` must match `CONTENT_API_KEY` in `cms-develop/.env`. Set `NEXT_PUBLIC_MEDIA_ORIGIN=http://127.0.0.1:8000`.
3. Run `npm install`, then `npm run dev` (http://localhost:3000). Set `LARAVEL_ORIGIN` so `/api/booking/*` and `/api/payment/*` are proxied to Laravel in development.

`npm test` runs the booking unit tests. After CMS data changes, delete `.next/cache/fetch-cache` before `npm run build`, or the build reuses cached API responses.

`npm run build` also needs Laravel running, because cabin pages are prerendered at build time.

## Layout

| Path | What |
|---|---|
| `design-system/tokens.json` | Design tokens (source of truth). Run `npm run tokens` to regenerate `src/styles/tokens.css` and `tokens.ts`. |
| `src/app/(en)`, `src/app/(vi)/vi` | Routes per language. English has no prefix; Vietnamese uses `/vi` plus translated slugs. Page files only re-export from `src/views`. |
| `src/views/<page>` | Page UI and route logic, shared by both languages |
| `src/components/{ui,layout,seo}` | Primitives, header/hero/footer, JSON-LD |
| `src/lib/api` | Server-only Content API client, zod schemas, cached readers (`'use cache'` + tags) |
| `src/messages/{en,vi}.ts` | UI strings |

## Rules

- **No client-side fetching of indexable content.** Content pages export `ensureStatic = 'navigation'`.
- **Pages with dynamic params also export `instant = false`.** Params are awaited outside `<Suspense>`, so 404 and 301 responses get correct status codes.
- **Components use semantic tokens only** (`--text-muted`, `--bg-inverse`…), never raw hex values.
- **Cache invalidation:** after content changes, Laravel calls `POST /api/revalidate` with `{ secret, tags }`. Tags are listed in `src/lib/api/content.ts`.

## Pages done

All public pages, in English and Vietnamese: homepage, itineraries (list + detail), cruise, cabin, experiences (list + detail), services, about, gallery, FAQ, blog (list, category, article, search, legacy redirects), legal pages, contact, booking, plus `robots.txt`, `llms.txt` and 404 pages. Legacy URLs (`/experience`, `/service`, old blog `-{id}.html`) redirect.

When a page is migrated, add its path pattern to `MIGRATED` in `src/lib/i18n.ts` (links to it then use client-side navigation) and route it to Next in Nginx. Sitemaps (`/sitemap*.xml`) are still generated by Laravel.
